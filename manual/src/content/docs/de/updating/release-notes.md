Bevor du eine Version herunterlädst, kannst du sehen, was sie ändert. Die Hinweise sind die, die auf GitHub zum Release geschrieben wurden, und erscheinen im Update-Dialog.

## Schritte

1. Bietet der Update-Dialog eine Version an, klicke unter dem Text auf *Was sich geändert hat*. Die Hinweise klappen im Dialog auf; lange scrollen.
2. Lies zuerst die **Highlights**, falls es welche gibt. Sie sind von Hand geschrieben und sagen, was dir auffallen wird: eine neue Funktion, ein geänderter Standard, etwas, das anders funktioniert.
3. Achte auf einen zitierten Absatz am Anfang oder in der Mitte. Dort warnt ein Release vor etwas – einer Einstellung, die neu vorzunehmen ist, einem Schritt von Hand, einer Version, von der es kein Zurück gibt.
4. Dann entscheidest du: *Herunterladen*, *Später erinnern* oder *Diese Version überspringen*. Siehe [Snotra Agent aktualisieren](../update-snotra/).

Das Feld gibt es auch im Schritt *Bereit*, nach dem Download, falls du die Hinweise vor dem Neustart lesen willst.

## Was du siehst

Snotra zeigt, was sich geändert hat, und lässt weg, was nur auf GitHub zählt: Die Zeilen der erzeugten Liste verlieren den Namen der Autorin oder des Autors und den Link zum Pull Request, die Liste neuer Mitwirkender und der Link zum vollständigen Vergleich entfallen. Übrig bleiben die Highlights und eine Zeile je Änderung.

Die Hinweise sind in jeder Oberflächensprache englisch, weil das Release so veröffentlicht wird. Den ganzen Text mit allen Links – den Pull Requests, dem vollständigen Vergleich – findest du in den [Releases auf GitHub](https://github.com/kkrafft1999/snotra/releases). Bei einer Installation, die sich nicht selbst aktualisiert, führt dich der Knopf *Release-Seite öffnen* im Dialog dorthin. Auf GitHub stehen auch die Hinweise übersprungener und älterer Versionen.

## Wenn es nicht klappt

- **Das Feld *Was sich geändert hat* fehlt.** Das Release hat keine Hinweise, oder Snotra konnte sie nicht lesen. Die Release-Seite zeigt, was es gibt.
- **Du willst die Hinweise einer Version, die du schon installiert hast.** Der Dialog zeigt sie nur, solange ein Update angeboten wird. Lies sie auf der [Releases-Seite](https://github.com/kkrafft1999/snotra/releases).
