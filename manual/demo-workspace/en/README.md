# Garden Planner

Plans which vegetables go into which bed, and when to sow them.

## What it does

- Keeps the beds with their size and hours of sun in `beds.json`.
- Knows each plant's spacing and sowing window from `plants.csv`.
- Builds a sowing calendar for the season (`src/calendar.js`).

## Status

The calendar works for spring. Summer sowings and crop rotation are still open,
see `notes/spring-2026.md`.
