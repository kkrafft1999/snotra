# Gartenplaner

Plant, welches Gemüse in welches Beet kommt und wann es gesät wird.

## Was es kann

- Führt die Beete mit Größe und Sonnenstunden in `beete.json`.
- Kennt Pflanzabstand und Saatzeitraum jeder Pflanze aus `pflanzen.csv`.
- Erstellt einen Aussaatkalender für die Saison (`src/kalender.js`).

## Stand

Der Kalender funktioniert für das Frühjahr. Sommeraussaat und Fruchtfolge sind
noch offen, siehe `notizen/fruehjahr-2026.md`.
